There are two kinds of piece:

- A **group** is a folder. It can hold other pieces, and it has prose of its own.
- A **section** is a single Markdown file.

To change the order, drag a row. To put a piece inside a folder, drop it *onto* the folder. Both rewrite the numeric prefixes on disk:

1. `010-groups-and-sections.md`
2. `020-units.md`
3. `030-whatever-comes-next.md`

Renaming a title never renames the file. The `id` in the header never changes either.
