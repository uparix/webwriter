A diagram drawn in draw.io is a picture too. Saved as an editable SVG, it shows in the text and the exports like any other picture, and draw.io still opens it to make changes. **Insert Diagram** draws a new one, and right-clicking a diagram edits it.

A tree shows how the book folder is laid out:

![The book folder](images/book-folder.drawio.svg){width=90%}

A workflow shows steps in order. Here a draft goes round until it is ready, then out to each export:

![From draft to export](images/writing-workflow.drawio.svg){width=90%}

The drawing and the draw.io file are one and the same. Change the arrows in draw.io, save, and the page shows the new version.

A Mermaid diagram is drawn from text instead, in a `mermaid` code fence, right where it stands. **Insert Mermaid Diagram** starts one; the next page shows a few.
