A unit says how a piece opens in the manuscript.

| Unit | Numbered | New page |
|:--------|:-------:|:-------:|
| Part | yes | yes |
| Chapter | yes | yes |
| Section | no | yes |
| Text | no | no |

This piece is *text*, so it carries on right under the table above it without a page break.
