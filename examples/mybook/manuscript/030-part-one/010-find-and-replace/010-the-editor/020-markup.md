The **Markup** menu and the command palette (⌘K) insert the fifteen constructs. Here is each one in use, except alignment, which has a page of its own in Part Two:

*Emphasis*, **strong**, and `inline code` wrap a selection. A [link](https://pandoc.org) wraps the selected words.

# A subsection

A line that starts with `#` is a subsection. Export shifts it below the piece's own title.

## A lower subsection

Two marks make the level under that.

- A bullet list
- with two items

1. A numbered list
2. counts by itself

> A quotation is set off from the text around it.
> It can run over several lines.

Hard line breaks are two spaces at the end of a line,
